📄 how_to_install.txt✕
  1. Click Download and run MentoxsLauncher-Setup.exe.
  2. Pick where to install it and click Install. It puts a shortcut on your desktop.
  3. Open the launcher, click CHATA, then INSTALL (about 250 MB).
  4. Press PLAY. That's it. Updates show up by themselves.
⚠ Windows may say "Windows protected your PC" because the launcher isn't signed by a big company. Click More info → Run anyway. It's safe, I made it.
